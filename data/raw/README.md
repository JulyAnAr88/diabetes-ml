# Raw Data

Place the original Kaggle dataset in this folder.

Source:
[`https://www.kaggle.com/api/v1/datasets/download/iammustafatz/diabetes-prediction-dataset`](https://www.kaggle.com/api/v1/datasets/download/iammustafatz/diabetes-prediction-dataset)

Expected file:
* `data/raw/diabetes-prediction-dataset`

Notes:
* Treat this folder as read-only after downloading the source data.
* Do not commit the raw CSV to the repository.
* If the downloaded filename is different, rename it to `diabetes-prediction-dataset.csv` or update the loading code explicitly.
